Lstar Tools 是一组快速、可靠且尊重隐私的在线小工具。无需注册，打开即用；图片、JSON 和文本均在你的浏览器本地处理，不会上传到服务器。

探索全部开发者工具

在线开发工具箱

选择适合下一项工作的工具：

  • 图片与 Base64 互转：在图片和 Base64 文本之间转换，支持预览、复制和下载。
  • JSON 格式化与结构编辑：校验、格式化、压缩、转义和编辑 JSON。
  • URL 编码解码：编码或还原 URL、查询参数和特殊字符。
  • MD5 加密：生成 32 位、16 位及大小写 MD5 摘要。
  • 时间戳转换：在秒级、毫秒级时间戳与日期时间间转换。

隐私优先的轻量工具

所有现有工具都在当前设备中完成处理。我们不会保存、上传或共享你的输入内容；刷新或关闭页面后，数据即由浏览器清除。

为什么选择 Lstar Tools？

我们专注于常用、直接且可靠的开发小工具，减少配置、等待和不必要的数据传输，让你把时间留给真正重要的工作。
