URL 编码解码

免费在线 URL 编码和解码工具。可处理完整 URL、查询参数与任意文本，支持中文、空格和常见特殊字符。

URL 编码与解码的作用

URL 编码会将中文、空格和特殊字符转换为可在网址与查询字符串中安全传输的百分号形式；解码会将编码文本还原为可读内容。

如何使用

  1. 粘贴完整 URL、查询参数或文本。
  2. 选择 URL 编码或 URL 解码。
  3. 复制处理结果到地址栏、代码或接口请求中。

隐私说明
