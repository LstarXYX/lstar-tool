JSON 格式化与结构编辑

免费在线 JSON 工具，可在浏览器本地校验语法、格式化缩进、压缩为单行、转义或移除一层转义，并通过树状结构编辑字段。

如何格式化 JSON

  1. 粘贴需要处理的 JSON 内容。
  2. 使用格式化、紧凑、转义或移除转义功能。
  3. 在树状结构中修改字段，原始 JSON 会同步更新。

常见问题

输入的 JSON 会上传或保存吗？

不会。解析和编辑均在当前浏览器内执行，刷新或关闭页面后本站不会保留内容。

格式化和紧凑有什么区别？

格式化会增加可读缩进；紧凑会移除无关空白以减小文本体积。
