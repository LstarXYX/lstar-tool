图片坐标框选工具

上传图片后，用矩形框选一个或多个区域，复制可用于标注和程序处理的原图像素坐标。

如何框选图片坐标

  1. 选择或拖拽一张图片上传；可清除当前图片并重新选择。
  2. 可进入全屏标注模式，自动适配整张图片后再放大并精细框选。
  3. 拖动矩形可移动位置，拖动矩形四角控制点可调整大小；用滚轮缩放、中键拖动画布，选中矩形后可用 Delete 或 Backspace 删除。
  4. 在右侧编辑每个框的名称，点击复制完整坐标数据。

坐标格式

每个标注使用 {"type":"rect","name":"person","id":"person_1","bbox":[x1,y1,x2,y2]} 格式。同名标注会按顺序自动编号，坐标按原图像素记录，不会受缩放和平移影响。

隐私说明

图片读取、预览和坐标计算完全在当前浏览器中完成，文件不会上传或保存到服务器。
